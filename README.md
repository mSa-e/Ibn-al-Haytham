# Ibn-al-Haytham

Building Ibn al-Haytham from Scratch in C :) oxox

## Features

1. Login and authentication
2. Student, admin, and staff interfaces
3. Database integration
4. Student schedules
5. Subject registration
6. Current GPA and GPA calculator
7. User profiles
8. Audit logs for every change made by admins and staff
9. Faculty and subject management, including credit-hour modifications
10. Admin ability to add students, remove students, and mark students as failed
11. Student grading by admins
12. Staff reports and restricted administrative access
13. University bylaws and locked subjects
14. Student registration restricted to admins
15. Quiz grades and reports
16. Announcements
17. Staff access restricted to their assigned students
